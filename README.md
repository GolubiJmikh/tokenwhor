# Токенвхор

Браузерная аркадная игра с виртуальными токенами.

## Возможности

- мини-игра с выигрышем и проигрышем токенов;
- ежедневный бонус;
- магазин предметов;
- профиль игрока;
- история транзакций;
- лидерборд;
- сохранение данных в localStorage.

## Запуск проекта

Установить зависимости:

```bash
npm install
```

Запустить режим разработки:

```bash
npm run dev
```

Создать production-сборку:

```bash
npm run build
```

Проверить сборку локально:

```bash
npm run preview
```

Проверка линтером:

```bash
npm run lint
```

## Технологии
