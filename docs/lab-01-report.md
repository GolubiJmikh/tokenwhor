### 2. Идея проекта

«Токенвхор» — браузерная аркадная игра, в которой игрок зарабатывает, тратит и накапливает виртуальные токены. Пользователь должен быстро понимать:

1. Сколько токенов у него сейчас.
2. Как быстро можно получить токены.
3. На что можно потратить токены.
4. Какой у него уровень и прогресс.
5. Какие игры и бонусы доступны прямо сейчас.

### 3. Пользовательская проблема

Игроку сложно отслеживать баланс, историю действий и прогресс в нескольких мини-играх одновременно. Без единого интерфейса игрок теряет мотивацию и перестаёт возвращаться в игру.

Приложение должно стать единой точкой входа в аркадный опыт: показывать текущий баланс, быстрые действия и мотивировать играть дальше.

### 4. Основная сущность

**Основная сущность проекта** — `TokenTransaction` (запись о движении токенов).

| Поле         | Тип               | Пример                | Назначение               |
| ------------ | ----------------- | --------------------- | ------------------------ |
| id           | string            | tx-001                | Уникальный идентификатор |
| type         | 'earn' \| 'spend' | earn                  | Тип операции             |
| amount       | number            | 150                   | Количество токенов       |
| source       | string            | roulette, daily_bonus | Источник операции        |
| timestamp    | string            | 2025-09-01T14:30:00Z  | Время операции           |
| description  | string            | Выигрыш в рулетке     | Описание для истории     |
| balanceAfter | number            | 1240                  | Баланс после операции    |

Модель содержит строку, число, дату и категорию. Это позволяет демонстрировать работу с разными типами данных в TypeScript.

### 5. Реализованная часть

**5.1. Начальный React-проект**  
Проект создан с помощью Vite + TypeScript. В корне находятся конфигурации Vite, TypeScript, `package.json`, `README.md` и `docs/project-spec.md`.

**5.2. Mock-данные**  
Демонстрационный массив транзакций находится в `src/data/mockTransactions.ts`.  
Баланс, уровень и история рассчитываются на клиенте из mock-данных и сохраняются в `localStorage`.

**5.3. Стартовый экран**  
Реализован экран лобби (`/`). На нём отображаются:

- текущий баланс токенов;
- уровень и прогресс;
- быстрые действия (Крутить, Бонус, Магазин);
- последние 3 транзакции.

Приложение не является статичным лендингом — на экране выполняются расчёты и отображаются данные из массива.

### 6. Спроектированные страницы

| №   | URL            | Страница        | Назначение                        |
| --- | -------------- | --------------- | --------------------------------- |
| 1   | `/`            | Лобби           | Баланс, быстрые действия, новости |

### 7. Пользовательские сценарии

**Сценарий 1. Крутить / играть**  
Пользователь заходит в лобби → нажимает «Крутить» → запускается мини-игра → после результата баланс и история обновляются автоматически.

**Сценарий 2. Получить ежедневный бонус**  
Пользователь заходит в лобби → нажимает «Получить бонус» → если бонус доступен, токены зачисляются и появляется запись в истории.

**Сценарий 3. Потратить токены**  
Пользователь открывает магазин → выбирает предмет → подтверждает покупку → токены списываются, предмет добавляется в профиль.

**Сценарий 4. Посмотреть историю**  
Пользователь переходит в «Историю» и видит все операции с фильтрацией по типу (earn/spend).

**Сценарий 5. Отслеживать прогресс**  
Пользователь открывает профиль и видит текущий уровень, количество сыгранных игр и ближайшие достижения.

### 8. Действия над сущностью

В следующих версиях с `TokenTransaction` планируется:

- создавать транзакцию;
- читать историю;
- фильтровать и сортировать;
- рассчитывать текущий баланс и уровень;
- начислять ежедневный бонус;
- списывать токены при покупке.

В лабораторной работе №1 эти действия зафиксированы как требования. Реализация CRUD и начисления/списания будет выполнена в следующих работах.

### 9. Границы первой версии

**В первую версию входят:**

- запуск React-приложения локально;
- типизированная модель `TokenTransaction`;
- mock-данные;
- стартовый экран (лобби);
- отображение баланса, уровня и последних транзакций;
- вычисляемые значения (уровень, прогресс);
- адаптивная вёрстка;

- Redux / Zustand;
- React Router и полноценная навигация;
- localStorage сохранение (будет добавлено);
- авторизация;
- реальные мини-игры с анимациями;
- API лидерборда.
