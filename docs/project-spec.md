# Спецификация проекта «Токенвхор»

## 1. Тема проекта

«Токенвхор» — браузерная аркадная игра с виртуальными токенами.

Игрок получает токены в мини-играх и за бонусы, тратит их в магазине, отслеживает статистику и соревнуется с другими игроками.

## 2. Пользователь

Пользователь — игрок браузерной аркадной игры, который хочет получать виртуальные награды, открывать предметы и отслеживать свой прогресс.

## 3. Пользовательская проблема

Игроку неудобно отслеживать баланс, историю выигрышей и покупок в разных частях приложения. Проект объединяет мини-игры, бонусы, магазин и статистику в одном интерфейсе.

## 4. Основная сущность

Основная сущность проекта — TokenTransaction, запись об операции с токенами.

| Поле         | Тип     | Назначение                                   |
| ------------ | ------- | -------------------------------------------- |
| id           | string  | Уникальный идентификатор операции            |
| description  | string  | Описание операции                            |
| amount       | number  | Количество начисленных или списанных токенов |
| category     | union   | Категория: game, bonus, purchase или quest   |
| status       | union   | Статус: completed или cancelled              |
| createdAt    | string  | Дата и время операции                        |
| isBonus      | boolean | Является ли операция бонусной                |
| balanceAfter | number  | Баланс после операции                        |

## 5. Страницы приложения

### 5.1. Лобби

URL: `/`

Назначение: основной экран приложения.

Отображаемые данные:

- баланс;
- уровень игрока;
- прогресс до следующего уровня;
- быстрые действия;
- последние транзакции.

Действия:

- начать игру;
- получить ежедневный бонус;
- открыть магазин;
- перейти в профиль.

### 5.2. Игровая комната

URL: `/game`

Назначение: запуск мини-игры.

Отображаемые данные:

- стоимость попытки;
- текущий баланс;
- результат игры.

Действия:

- запустить рулетку;
- получить выигрыш или проигрыш.

### 5.3. Магазин

URL: `/shop`

Назначение: покупка виртуальных предметов.

Отображаемые данные:

- список предметов;
- описание;
- цена;
- статус покупки;
- баланс игрока.

Действия:

- купить предмет;
- просмотреть уже купленные предметы.

### 5.4. Профиль

URL: `/profile`

Назначение: просмотр статистики игрока.

Отображаемые данные:

- уровень;
- баланс;
- количество сыгранных игр;
- количество побед;
- достижения.

Действия:

- просмотреть прогресс;
- проверить достижения.

### 5.5. История

URL: `/history`

Назначение: просмотр всех операций.

Отображаемые данные:

- описание операции;
- дата;
- категория;
- сумма;
- баланс после операции.

Действия:

- просматривать историю;
- анализировать начисления и списания.

### 5.6. Лидерборд

URL: `/leaderboard`

Назначение: рейтинг игроков.

Отображаемые данные:

- место игрока;
- имя;
- количество токенов.

Действия:

- просматривать рейтинг;
- сравнивать свой результат с другими игроками.

## 6. Пользовательские сценарии

### Сценарий 1. Игра

Пользователь открывает лобби, переходит в игровую комнату, запускает рулетку и получает выигрыш или проигрыш. История и баланс обновляются.

### Сценарий 2. Получение бонуса

Пользователь открывает лобби и нажимает кнопку ежедневного бонуса. Если бонус ещё не был получен сегодня, баланс увеличивается.

### Сценарий 3. Покупка предмета

Пользователь открывает магазин, выбирает предмет и нажимает кнопку покупки. При достаточном балансе токены списываются, а предмет отмечается как купленный.

### Сценарий 4. Просмотр истории

Пользователь открывает страницу истории и просматривает список всех начислений и списаний.

### Сценарий 5. Проверка прогресса

Пользователь открывает профиль и смотрит текущий уровень, количество игр, победы и достижения.

## 7. Действия над сущностью

- создание транзакции;
- начисление токенов;
- списание токенов;
- просмотр истории;
- фильтрация по категориям;
- расчёт текущего баланса;
- расчёт уровня;
- сохранение данных в localStorage;
- отображение результата мини-игры.

## 8. Границы первой версии

В первую версию входят:

- React-приложение на Vite и TypeScript;
- шесть отдельных маршрутов;
- мини-игра;
- ежедневный бонус;
- магазин;
- профиль;
- история;
- лидерборд;
- localStorage;
- адаптивная вёрстка.

В первую версию не входят:

- backend;
- база данных;
- авторизация;
- реальные платежи;
- серверный лидерборд;
- мультиплеер;
- подключение внешнего API;
- мобильное приложение.
